# Architecture decision records

Decision records explain project-wide choices that future code should preserve.
They use this lifecycle:

- **Proposed**: under discussion; not yet authoritative.
- **Accepted**: the project should follow it.
- **Superseded**: replaced by a newer numbered record.

Create records as `NNNN-short-title.md` using:

```markdown
# ADR NNNN: Title

- Status: Proposed
- Date: YYYY-MM-DD

## Context

## Decision

## Consequences
```
